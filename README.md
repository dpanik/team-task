# Team Task Board

Готовое интерактивное веб-приложение для управления задачами небольшой команды.

## Запуск

Откройте `index.html` в браузере или запустите любой статический сервер:

```powershell
python -m http.server 8080
```

После этого откройте `http://localhost:8080/team-task-board/`.

Данные сохраняются локально в `localStorage` браузера. Сервер и сборка не требуются.
